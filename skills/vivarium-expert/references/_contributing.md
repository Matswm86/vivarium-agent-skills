# Contributing

One rule per file. Keep files under ~2 KB so an agent can load several without burning context.

## Rules for this skill

1. **Every load-bearing number carries a URL.** A number without a source is not a rule, it is a guess.
2. **Label your own arithmetic `(my calc)`.** Never place a calculated figure next to a citation as though the source produced it.
3. **Write `UNVERIFIED` rather than guessing.** An honest gap is useful; a plausible invention is not.
4. **When sources conflict, show both and name the conflict.** Do not silently pick a winner.
5. **Prefer the failure over the theory.** State what breaks first, then explain why.
6. **No jurisdiction-specific law.** Legal requirements for keeping animals vary by country and change; this skill covers physics, biology, and construction only. Point the reader at their national authority instead.

## File naming

`<category-prefix>-<slug>.md`, lowercase, hyphenated. See `_sections.md` for valid prefixes.

## Adding a species

Species files must state: adult size, the parameter band (temperature, and pH/hardness where aquatic), minimum enclosure footprint, and at least one named incompatibility. A species entry with no incompatibility listed has not been researched.
