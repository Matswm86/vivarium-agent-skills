## Name the tension instead of hiding it

The standard hobby canopy list is botanically **Neotropical**, not SE Asian:

- *Neoregelia*, *Vriesea*, *Tillandsia*, *Aechmea*, *Cryptanthus* — all Bromeliaceae, exclusively New World.
- *Marcgravia* — Neotropical.
- *Anthurium* and *Philodendron* — exclusively New World Araceae.

**None occur naturally anywhere near Borneo, Sumatra, or the Philippines.**

That does not make the plants wrong to keep. It means the "authentic SE Asian rainforest" framing and the actual species list are in tension. Two honest paths:

1. **Botanically accurate SE Asian palette** — replace the Neotropical canopy and epiphyte genera with real Asian equivalents filling the same visual roles.
2. **Mixed-continent "rule of cool"** — keep the plants, drop the biotope claim.

**Pick one deliberately and state it.** A build described as a biotope should be a biotope; a build assembled for looks should be described that way. The failure mode is not the plant list, it is a claim the plant list does not support.
