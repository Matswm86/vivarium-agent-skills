## Cold susceptibility is not one curve

Freezing wild-collected moss or litter at household -18 C removes some animals and none of the microbes. Mold appearing days after planting "frozen-sterilized" moss is the expected outcome, not a failed freeze.

**Wrong:**

```
Wild moss → -18 C for 4-5 days → "sterile" → plant   # spores, springtails, chytrid all survive
```

**Right:**

```
Wild moss → rinse hard → quarantine 4-6 weeks in a sealed, springtail-seeded box
→ plant, and expect the normal new-build bloom anyway
```

**Why:** measured supercooling points: isopods (*Porcellio scaber*) ≈ -7 C with LT50 of -1.4 to -4.6 C, so -18 C kills them; Collembola span -2 to -44 C via glycerol cryoprotectants, so many temperate springtails ride out -18 C. Fungal culture collections store spores frozen on purpose (long-term preservation runs below -130 C; a home freezer neither kills nor preserves reliably). Chytrid (*Bd*) survives cold — zoospores last twice as long at 4-14 C as at 23 C — and dies at 26-30 C, so a warm quarantine is the anti-chytrid direction, not a freezer. No sterilization protocol that keeps moss alive exists in any reachable source; heat thresholds (`bioactive-leaf-litter-sterilisation.md`) apply to dead litter only.

**Verify:** put a pinch of the frozen moss in a sealed deli cup for a week at room temperature; springtails walking the lid and fresh hyphae both falsify "sterile."

**Sources:**
- https://link.springer.com/article/10.1007/BF00346927 — P. scaber cold adaptation, SCP ≈ -7 C
- https://www.sciencedirect.com/science/article/abs/pii/S0306456518301414 — cold-tolerance screening across springtail species
- https://www.atcc.org/resources/technical-documents/preservation-and-recovery-of-filamentous-fungi — fungal storage temperatures
- https://journals.plos.org/plosone/article?id=10.1371%2Fjournal.pone.0073830 — Bd lethal maximum 26-29 C, strain-dependent
- https://microbewiki.kenyon.edu/index.php/The_Temperature_Relationship_of_Batrachochytrium_dendrobatidis — Bd zoospore survival 48 h at 4-14 C vs 24 h at 23 C

**Unverified:** no direct -18 C / 96 h kill-rate study exists for any of these organisms; the verdicts above are inferred from supercooling and storage literature. Gastropod-egg freeze tolerance was not retrieved.
